# Multiple-Year Sample Workbooks

Use this folder to try the generator's `multiple` mode.

The folder contains two Excel workbooks:

- `Policy_111_Multi_Year.xlsx` has qualifying rows for financial years `2024` and `2026`, plus rows that should be ignored by the transaction/reversal filters.
- `Policy_222_Multi_Year.xlsx` has qualifying rows for financial year `2027`, including December and January transactions in the same March-through-February financial year.

When prompted for years in multiple mode, use:

- `Policy_111_Multi_Year.xlsx`: `2024,2026`
- `Policy_222_Multi_Year.xlsx`: `2027`
